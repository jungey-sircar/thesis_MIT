frozen-feature protocol is widely adopted for assessing representation quality~\\cite{chen2020simclr, he2022mae}. In this protocol, model weights are frozen during downstream evaluation; only lightweight classifiers are trained on extracted features. This study extends the standard protocol by evaluating both classical machine learning classifiers (SVM, KNN, Random Forest, MLP, Logistic Regression) and custom PyTorch neural network architectures (DeepMLP, ResMLP, Conv1DNet, MiniTransformer, AttentionPoolMLP, CosineClassifier) on top of frozen features. This design choice provides several methodological advantages:\n81: \n82: \\begin{enumerate}[leftmargin=*]\n83:     \\item \\textbf{Isolates Intrinsic Representation Quality:} By preventing any task-specific weight updates to the backbone, the protocol measures the quality of representations as-learned during pretraining.\n84:     \\item \\textbf{Ensures Fair Cross-Scale Comparison:} V-JEPA~2 (654M) and Qwen2.5-VL (7B) differ by an order of magnitude in parameter count. Fine-tuning could disproportionately benefit the larger model by providing more adaptive capacity.\n85:     \\item \\textbf{Enables Resource-Constrained Evaluation:} No gradient computation is needed for the main model, requiring only a forward pass for feature extraction.\n86:     \\item \\textbf{Simulates Practical Deployment:} In many real-world scenarios, pretrained models are deployed as fixed feature extractors with lightweight heads.\n87:     \\item \\textbf{Comprehensive Classifier Coverage:} By using 11 classifiers spanning linear probes, kernel methods, ensemble methods, and deep neural networks, the evaluation provides a thorough assessment of feature quality across diverse classification paradigms.\n88: \\end{enumerate}\n89: \n90: \\section{Dataset Description}\n91: \n92: \\subsection{FineGym Dataset}\n93: \n94: The FineGym annotation file (v1.1) maps YouTube video IDs to hierarchical activity annotations with event IDs and timestamps.
